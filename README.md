
🎵 Emotion-Based Music Recommender (Image Input + Spotify Integration)
This project captures a user's image, detects their emotion using facial expression recognition, and recommends a Spotify playlist based on the detected mood.

💡 Features
📸 Capture user emotion using webcam

😄 Detect emotions like Happy, Sad, Angry, Neutral, etc.

🎶 Recommend a mood-based Spotify playlist

🔗 Direct Spotify playlist links based on emotions

🛠️ Tech Stack
Python 3.x

OpenCV (cv2) – image handling

FER (fer) – facial emotion recognition

Spotify links – static playlists (can be extended with Spotify API)

🖥️ How It Works
Capture your image using your webcam (Google Colab or local setup).

Detect the emotion using the FER model.

Recommend and display a Spotify playlist link based on the emotion.
